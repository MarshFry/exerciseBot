# Exercise Bot

Telegram-бот для записи тренировок.

## Зачем нужен проект

Бот помогает сохранять упражнения, вес и количество повторений. Он показывает прошлые результаты, чтобы их было удобно сравнивать с новыми.

## Что умеет бот

- предложить выбрать группу мышц и упражнение;
- дать добавить своё упражнение;
- сохранить вес и количество повторений;
- показать историю тренировок и последние результаты по упражнению.

## Что понадобится

- Java 8 или новее;
- IntelliJ IDEA;
- Maven (обычно IntelliJ настраивает его для проекта автоматически);
- Telegram-бот и его токен.

## Установка и запуск

1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) и скопируйте его токен.
2. Откройте папку проекта в IntelliJ IDEA. Если появится предложение загрузить Maven-зависимости, согласитесь.
3. Откройте **Run → Edit Configurations…** и создайте конфигурацию типа **Application**.
4. В поле **Main class** укажите `main.Main`.
5. В поле **Environment variables** добавьте `TOKEN=ваш_токен`.
6. Нажмите **Run**.
7. Найдите бота в Telegram и отправьте `/start`.

Токен — это секретный ключ. Не публикуйте его и не добавляйте в файлы проекта.
В коде указано имя бота `ExerciseBot_marshFry`. Если вы создали другого бота, замените это имя в `src/main/java/main/GymBot.java`.

## Где хранятся данные

При первом запуске автоматически создаётся файл `gym_bot.db` в папке, из которой запущен бот. В нём хранятся упражнения и записи тренировок. Не удаляйте этот файл, если хотите сохранить историю.

## Как пользоваться

1. Отправьте боту `/start`.
2. Выберите группу мышц, затем упражнение или введите новое название.
3. Введите вес и повторения через пробел, например: `80 10`.
4. Нажмите **История**, чтобы посмотреть сохранённые тренировки.

Чтобы записать подход с новым весом или количеством повторений, введите новые значения. Ввод с десятичной дробью тоже подходит: `80.5 10`.
